# 🎨 MJ Prompt Generator

Midjourney / Niji 提示词生成器 - 快速生成专业级AI绘画提示词

## ✨ 功能特点

- 📷 支持参考图片链接（ImgBB图床）
- 🏷️ 丰富的风格标签库（中英双语）
- ⚙️ 完整的MJ参数配置
- 🌐 多个在线提示词搜索引擎快捷入口
- 📋 一键复制生成的提示词

## 🌐 在线搜索支持

集成了8个免费提示词搜索网站：
- Lexica.art - SD提示词搜索引擎
- PromptHero - 最大提示词社区
- OpenArt - AI艺术与提示词
- Civitai - 模型与提示词分享
- Arthub.ai - AI作品灵感库
- MidLibrary - Midjourney风格库
- Krea.ai - AI图像探索
- PromptBase - 提示词市场

## 🚀 使用方法

1. 直接打开 `index.html` 本地使用
2. 或部署到 GitHub Pages 在线访问
